# UI_GUIDELINES.md — UI/UX Conventions

## Design Language

This project uses a **cinematic, glassmorphism-based design** with neon accents and dark/light mode support. The aesthetic is inspired by premium presentation tools — immersive, scroll-snapping, full-viewport slides.

## Typography

- **Font Family:** Inter (Google Fonts), weights 300–800
- **Slide Title:** 3.5rem, `text-shadow: var(--neon-glow)`, `fadeInDown` animation
- **Slide Subtitle:** 1.5rem, `var(--text-muted)`, `fadeInUp` animation
- **Body/Card Text:** Default size, `line-height: 1.75`
- **Heading Tracking:** `letter-spacing: -0.01em`
- **Mobile Title:** 1.4rem (forced via `!important`)

## Component Library

### Glass Card

The primary content container. Uses `backdrop-filter: blur(10px)`, semi-transparent background, rounded corners (16px), and shadow.

- Base class: `.glass-card`
- Interactive: add `.hover-magnify`
- Emphasis: add `.border-glow-blue` or accent border-top via inline style
- On hover: neon glow box-shadow

### Slide Number Badge

Auto-injected pill at bottom-right of each slide. Glassmorphism style, clickable dropdown for slide navigation.

- Classes: `.sn-badge`, `.sn-dropdown`, `.sn-dropdown__item`
- Positioned: `position: absolute; bottom: 1.5rem; right: 1.1rem`
- On desktop: shifted to `right: 3.2rem` to avoid progress dots

### Progress Dots

Vertical dot indicators at the right edge. Auto-generated by `main.js`. Active dot scales and glows cyan.

### Theme Toggle

Fixed pill button at bottom-left. Shows sun icon in dark mode, moon in light mode. Persists preference to localStorage.

### Chapter Navigation

Fixed pill bar at top-center. Links to all 7 chapters with hover tooltips (`data-fullname`). Active chapter highlighted with accent colour.

### Popup Overlay

Full-screen modal with blur backdrop. Shows formula, raw data, and "why it matters" for statistical metrics. Triggered on hover via `data-popup` attribute.

### Lightbox Slider

Full-screen image viewer with prev/next navigation. Keyboard support (arrows, Escape). Used for timeline and pillar detail images.

### Resource Cards

Gradient-glow cards on the homepage. Use `data-gradient` attribute (`pink`, `cyan`, `purple`) for the glow effect beneath.

## Interaction Patterns

| Interaction | Behaviour |
|---|---|
| Scroll | Full-page scroll-snap (mandatory, Y axis) |
| Arrow keys | Up/Down navigate between slides |
| Card hover | Scale 1.5× with glow (desktop), 1.02× (mobile) |
| Theme toggle | Smooth CSS variable transition, charts re-render |
| Popup trigger hover | Shows statistical insight overlay |
| Badge click | Opens slide navigation dropdown |
| Lightbox click | Opens full-screen image viewer |

## Responsive Breakpoints

| Breakpoint | Changes |
|---|---|
| ≤1024px | Title → 2.5rem, `.grid-4` → 2 columns |
| ≤768px | All grids → 1 column, cards → compact row layout, icons shrink, progress dots hidden, pyramids → flat rectangles, hover-magnify → 1.02× |
| ≤600px | CES grid → 1 column |

---

## Cinematic Effects

- **Slide fade-in:** Elements fade up with staggered delays using `cinematic-fade-in` animation, triggered by IntersectionObserver adding `.is-visible` class
- **Page load reveal:** First slide content uses `page-load-reveal` animation with sequential delays
- **Background gradients:** Each slide has subtle radial gradients (blue at 20% left, orange at 80% right) that differ between themes
- **Breathing glows:** Cards can have continuous pulsing border glow animations (e.g., `.glow-blue`)

## Text Rules

- Always use **"betterment of society"** — never "societal betterment"
- `main.js` includes a DOM walker and MutationObserver that auto-corrects any occurrence at runtime
